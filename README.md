# IllI 言語仕様

IllI（イリー）は、次の8文字だけでプログラムを書く極小言語です。

```text
i I l ! | [ ] 1
```

見た目がよく似た `i`、`I`、`l`、`1` を意図的に採用しています。
実行モデルは Brainfuck に近い、テープとデータポインタを持つ機械です。

## 1. ソースコード

IllI のソースコードはバイト列です。使用できるバイトは次の8種類に限ります。

```text
iIl!|[]1
```

- 大文字と小文字は区別します。
- 空白、タブ、改行、コメントは使用できません。
- 空のソースコードは、何もせず正常終了するプログラムです。
- ファイル名の拡張子には `.illi` を推奨しますが、実行には影響しません。
- 指定外のバイトを1つでも含むソースコードは不正です。

形式的には、ソースコードの字句構造を次のように表せます。

```ebnf
program = { "i" | "I" | "l" | "1" | "!" | "|" | "[" | "]" } ;
```

さらに、すべての `[` と `]` は正しく対応していなければなりません。括弧は入れ子にできます。

## 2. 仮想機械

IllI プログラムは、次の状態を持つ仮想機械上で実行されます。

- **テープ**: 整数で番号付けされたセルの並び。左右どちらにも無制限に伸びます。
- **セル**: 0から255までの符号なし8ビット整数。すべての初期値は0です。
- **データポインタ**: 現在選択しているセルの番号。初期値は0です。
- **命令ポインタ**: 次に実行するソースコード上の命令位置。初期位置は先頭です。
- **入力**: 0個以上のバイトからなる入力ストリーム。
- **出力**: 実行中に生成されるバイトストリーム。初期状態は空です。

セル番号には負の整数も使用できます。したがって、初期位置から `1` を実行しても範囲外エラーにはなりません。

## 3. 命令

「現在値」は、データポインタが指すセルの値を意味します。

| 命令 | 動作 | Brainfuck相当 |
|---|---|---|
| `i` | 現在値を1増やす。255の次は0になる | `+` |
| `I` | 現在値を1減らす。0の次は255になる | `-` |
| `l` | データポインタを1増やし、右のセルへ移動する | `>` |
| `1` | データポインタを1減らし、左のセルへ移動する | `<` |
| `!` | 現在値を1バイトとして出力へ追加する | `.` |
| `\|` | 入力から1バイト読み、現在のセルへ格納する | `,` |
| `[` | 現在値が0なら、対応する `]` の直後へ移動する | `[` |
| `]` | 現在値が0でなければ、対応する `[` の直後へ移動する | `]` |

命令の実行後は、ジャンプが発生した場合を除き、命令ポインタを次の命令へ進めます。

### 3.1 算術

`i` と `I` の計算は256を法として行います。

```text
255 + 1 = 0
0 - 1 = 255
```

オーバーフローやアンダーフローは実行時エラーになりません。

### 3.2 入出力

入出力の単位は文字ではなく、0から255までの**1バイト**です。

- `!` は現在値をそのまま出力します。
- `|` は次の入力バイトを現在のセルへ上書きします。
- 入力をすべて読み終えた後に `|` を実行すると、現在のセルへ0を格納します。

文字コードは言語仕様では定めません。ASCIIやUTF-8などの解釈は、プログラムと利用者に委ねられます。CLIの `--input` に渡した文字列はUTF-8へ変換されます。

### 3.3 ループ

`[` と `]` は対応する一組でループを作ります。`[` に到達した時点で現在値が0ならループを抜け、0でなければ本体を実行します。`]` に到達した時点で現在値が0でなければ、再びループ本体の先頭へ戻ります。

たとえば `iii[I]` はセル0を3にした後、0になるまで `I` を繰り返します。終了時のセル0は0です。`[i]` のように終了条件へ到達しないコードは無限ループになることがあります。

## 4. 実行手順

処理系は実行前にソースコードを検査します。

1. 指定された8文字以外がないか検査する。
2. `[` と `]` の対応関係を、入れ子を考慮して決定する。
3. テープ、各ポインタ、入出力を初期化する。
4. 先頭から命令を1つずつ実行する。
5. 命令ポインタがソースコード末尾を越えたら正常終了する。

実行時間やテープ使用量に、言語仕様上の上限はありません。プログラムが必ず終了する保証もありません。実際の処理系では、実行環境のメモリなどによる制限を受けます。

## 5. エラー

次のソースコードは実行前エラーです。

- 8種類以外のバイトを含む。
- 対応する `]` がない `[` を含む。
- 対応する `[` がない `]` を含む。

エラー位置は、ソースコード先頭を1とするバイト位置で報告されます。構文が正しいプログラムには、ゼロ除算やテープ範囲外などの言語上の実行時エラーはありません。

## 6. プログラム例

### 入力を1バイトそのまま返す

```text
|!
```

### `@` を出力する

最初のセルに8を作り、それを8回加算して64を作ります。ASCIIでは64が `@` です。

```text
iiiiiiii[liiiiiiii1I]l!
```

処理の流れは次のとおりです。

1. セル0を8にする。
2. ループごとにセル1へ8を足し、セル0から1を引く。
3. セル0が0になったらセル1へ移動する。
4. 値64を出力する。

### 入力を終端まで出力する

```text
|[!|]
```

入力中の値0を終端として扱います。入力がなくなると `|` が0を格納するため、ループが終了します。途中に値0を含むバイナリ入力では、そこで終了します。

## 7. Brainfuckとの変換

IllI は各命令を1対1で Brainfuck に変換できます。

```text
Brainfuck: + - > < . , [ ]
IllI:      i I l 1 ! | [ ]
```

ただし、Brainfuckにはセル幅、テープ範囲、入力終了時の挙動が処理系ごとに異なる場合があります。IllIでは、それらを「8ビットセル」「双方向無限テープ」「入力終了時は0」と明確に定めています。

## 8. IllIを使用する流れ

### 8.1 環境を準備する

この手順では、Pythonがすでにインストールされているものとします。外部ライブラリやパッケージの追加インストールは必要ありません。

実行に最低限必要なのは、リファレンス処理系の `illi.py` です。テストも行う場合は `test_illi.py` を同じディレクトリへ置きます。

```text
IllI/
├── illi.py
├── test_illi.py
└── README.md
```

ターミナルを開き、ファイルを置いたプロジェクトディレクトリへ移動します。

```console
$ cd path/to/IllI
```

リファレンス処理系にはPython 3.9以降が必要です。使用できるバージョンを確認します。

```console
$ python3 --version
Python 3.9.0
```

続けてヘルプが表示されることを確認します。

```console
$ python3 illi.py --help
```

使い方が表示されれば環境構築は完了です。以降の操作は、このプロジェクトディレクトリ内で行います。

### 8.2 プログラムを作成する

拡張子 `.illi` のファイルを作り、8種類の命令だけでプログラムを書きます。
たとえば、入力された1バイトをそのまま出力する `echo.illi` の内容は次のとおりです。

```text
|!
```

IllIでは改行も禁止文字です。一般的なテキストエディタが末尾へ改行を自動追加する場合は、その設定を無効にしてください。ターミナルから作る場合は、末尾改行を付けない `printf` を使用できます。

```console
$ printf '|!' > echo.illi
```

### 8.3 プログラムを実行する

第1引数にソースファイルのパスを指定します。

```console
$ python3 illi.py echo.illi
```

この例は入力を待つ対話式プログラムではありません。入力を指定しなければ、`|` は入力終了として0を読み取ります。

### 8.4 入力を渡す

`--input` オプションでプログラムの入力を指定します。

```console
$ python3 illi.py echo.illi --input A
A
```

入力文字列はUTF-8のバイト列へ変換されます。`|` 1個につき1バイトだけ読み取るため、上のプログラムが出力するのは先頭の1バイトです。

複数バイトを終端まで複写する場合は、次のプログラムを使えます。

```console
$ printf '|[!|]' > copy.illi
$ python3 illi.py copy.illi --input Hello
Hello
```

### 8.5 結果を確認する

`!` が出力するのは文字ではなく生のバイトです。表示可能なASCII値なら文字として見えますが、値0や255などは端末上で見えない場合があります。バイト値を確認したいときは、`od` などへ渡します。

```console
$ printf 'iii!' > three.illi
$ python3 illi.py three.illi | od -An -tu1
   3
```

### 8.6 エラーを修正する

不正な文字や対応しない括弧がある場合、処理系はエラー位置を表示し、終了ステータス1で終了します。

```console
$ printf 'i i' > invalid.illi
$ python3 illi.py invalid.illi
illi: 2: forbidden character ' '
```

位置はソースコード先頭を1としたバイト数です。空白や見えない末尾改行も1文字として数えられます。

### 8.7 開発時にテストする

処理系自体が正しく動作するか確認するには、プロジェクトのディレクトリでテストを実行します。

```console
$ python3 -m unittest -v
```

すべての項目に `ok` と表示されれば成功です。

## 9. リファレンス処理系

Python 3.9以降で実行できます。

```console
$ python3 illi.py program.illi
$ python3 illi.py echo.illi --input A
```

基本的なコマンド:

```console
$ python3 -m unittest -v
```
