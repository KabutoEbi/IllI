# IllI

`i I l ! | [ ] 1` の8文字だけで書く、極小プログラミング言語です。
見分けにくい文字を眺めながら、1バイト単位で計算します。

## 命令

| 文字 | 動作 |
|---|---|
| `i` | 現在のセルに1を足す |
| `I` | 現在のセルから1を引く |
| `l` | 右のセルへ移動する |
| `1` | 左のセルへ移動する |
| `!` | 現在のセルを1バイト出力する |
| `\|` | 入力を1バイト読む（入力終了時は0） |
| `[` | 現在値が0なら対応する `]` へ進む |
| `]` | 現在値が0でなければ対応する `[` へ戻る |

セルは0から255までで循環し、テープは左右へ無制限に伸びるものとします。
言語の一部ではない空白・改行・コメントも禁止です。

## 実行

Python 3.10以降だけで動きます。

```console
$ python3 illi.py program.illi
$ python3 illi.py echo.illi --input A
```

たとえば `|!` は、1文字を読み、そのまま出力するプログラムです。
`iiiiiiii[liiiiiiii1I]l!` は `@` を出力します。
